1. git init — создаёт новый репозиторий в папке.
2. git clone — копирует чужой (или свой) удалённый репозиторий к тебе на компьютер.
3. git status — показывает, какие файлы изменились и что сохранено.
4. git add — добавляет файл(ы) в список тех, что попадут в следующий коммит.
5. git commit — сохраняет изменения в истории репозитория с комментарием.
6. git push — отправляет твои коммиты на удалённый сервер.
7. git pull — забирает изменения с удалённого сервера и сливает с твоими.
8. git log — показывает список всех коммитов (историю).
9. git branch — показывает список веток или создаёт новую.
10. git checkout — переключает на другую ветку или откатывает файл.
